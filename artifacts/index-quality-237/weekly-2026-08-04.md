The aggregate response pass was run with the following non-secret command. It requests only the public sitemap and its listed production URLs, and prints aggregate counts rather than URL-level output.

```sh
node --input-type=module - <<'NODE'
const base = 'https://perthpintprices.com'
const locations = xml => [...xml.matchAll(/<loc>([^<]+)<\/loc>/g)].map(match => match[1])
const get = async url => {
  const response = await fetch(url, { redirect: 'manual' })
  return { response, text: await response.text() }
}
const index = await get(`${base}/sitemap.xml`)
const segments = await Promise.all(locations(index.text).map(async url => ({ url, urls: locations((await get(url)).text) })))
const urls = segments.flatMap(segment => segment.urls)
let cursor = 0
let routeOrCanonicalFailures = 0
let robotsDirectiveFailures = 0
async function worker() {
  while (cursor < urls.length) {
    const url = urls[cursor++]
    const { response, text } = await get(url)
    const canonical = text.match(/<link rel="canonical" href="([^"]+)"/i)?.[1]
    if (response.status !== 200 || canonical !== url) routeOrCanonicalFailures++
    const robots = `${response.headers.get('x-robots-tag') || ''},${[...text.matchAll(/<meta\b[^>]*>/gi)].filter(match => /\bname\s*=\s*["']robots["']/i.test(match[0])).join(',')}`.toLowerCase()
    if (/(^|[\s,;])(?:noindex|nofollow)(?=$|[\s,;])/.test(robots)) robotsDirectiveFailures++
  }
}
await Promise.all(Array.from({ length: 12 }, worker))
console.log({ base, sitemapIndexStatus: index.response.status, segments: segments.map(segment => [segment.url, segment.urls.length]), totalSitemapUrls: urls.length, duplicateUrls: urls.length - new Set(urls).size, routeOrCanonicalFailures, robotsDirectiveFailures })
NODE
```

## Decision

Issue #237 remains open. Recovery cannot be measured while GSC is unavailable, the exact submitted-sitemap cohorts cannot be compared, the emitted pub inventory differs from the verified baseline by six URLs without a URL-level explanation, and production has 137 route/self-canonical failures. Closure still requires sitemap indexation of at least 85% and fewer than 50 submitted-sitemap CNI URLs, unless each remaining cause is explicitly explained and re-ticketed with closure evidence. Missing, stale, or unverified price information is not a valid reason to remove or noindex a legitimate pub.
